`npm run dev` starts the Vite dev server on port 3000 (proxying `/api` to `http://127.0.0.1:8181`). `npm start` launches Electron which spawns the FastAPI server automatically. `npm run package` builds a Windows debug installer (`--win --dir`); `npm run dist` produces a signed x64 NSIS installer without publishing. The Python backend must be available as `carrot.app` on port 8181 before the renderer can communicate with it.
