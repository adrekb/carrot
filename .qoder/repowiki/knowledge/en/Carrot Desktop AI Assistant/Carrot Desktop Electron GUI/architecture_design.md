The module is a standard Electron application with three entry points: `main.js` (Node process), `preload.js` (context bridge), and Vite-built React assets served from `public/`. `main.js` creates two BrowserWindow instances — a main app window loading `public/index.html` and a transparent, always-on-top overlay window loading `public/overlay.html` — and spawns a Python FastAPI server (`python -m carrot.app`) on port 8181 via `child_process.spawn`. Renderer code communicates with the Node layer exclusively through `ipcMain.handle` / `ipcRenderer.invoke` exposed by `preload.js`, which whitelists only `sendCommand`, `getStatus`, `onSpeechResult`, and `onSpeechError` on `window.carrotAPI`. The overlay window bypasses IPC and calls the FastAPI endpoint directly via `fetch`, then posts results back to the parent window using `postMessage`. Vite config builds React output into `public/` and proxies `/api` requests to the FastAPI server during development. `electron-builder` packages the app for Windows NSIS installers, bundling `main.js`, `preload.js`, and the built `dist/**/*` assets.
